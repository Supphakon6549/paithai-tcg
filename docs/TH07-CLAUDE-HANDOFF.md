## งานที่ขอให้ Claude ทำ
- เชื่อมเอฟเฟกต์ทั้ง16ใบตามเอกสาร ไม่อ่าน effectText แล้วเดากฎเพิ่ม
- ใช้ groupTag naga-court กรองนาคา ไม่ใช้ reptile ทั้งหมด ไม่อิงชื่อบนภาพ
- เพิ่มเหตุการณ์มอนสเตอร์หงายที่เป็นเจ้าของและควบคุมกลับจากสนามขึ้นมือด้วยเอฟเฟกต์ พร้อม physical/hand-entry; ไม่รวมกลับextra คืนเป็นต้นทุน หรือสุสาน→มือ
- จัดคิว trigger หลังเอฟเฟกต์แม่แก้ครบ และ hard once-per-name ต่อผู้เล่นต่อเทิร์น; คืนมือ/เรียกใหม่ไม่รีเซ็ตในเทิร์นเดียว
- 002/011 ค้นเมื่ออัญเชิญจากมือแบบหงาย ทั้งnormal/special; ไม่รวมจากกอง สุสาน หรือพลิก
- 001 เกราะหนึ่งchargeร่วม battle/effect; 004 pact สงบศึกพร้อม LP500 เฉพาะครบเงื่อนไขที่expiry; 005 กาลแยกจากgrowth; 006 ต้นทุนส่งการ์ดคว่ำและลดATKหนึ่งbattle
- 007/008 ตรวจจังหวะกลับมือ; 008ต้องอยู่มือก่อนเหตุ ไม่ย้อนหลังจากการจั่ว007 และเรียกใบที่กลับได้เฉพาะhand-entryเดิม
- 009 specialพร้อมจำกัดspecialนาคาหลังสำเร็จ; 010กันการต่อสู้และLPหนึ่งครั้งต่อชื่อ; 012/013 คืนแล้วทำขั้นต่อไปเฉพาะคืนสำเร็จ; 014ทำลายเวท/กับดัก ไม่ใช่negate
- 015/016 สูตรผสานนาคาชื่อต่างกัน3ใบจริงจากมือ/สนาม อยู่กองพิเศษ ไม่ขึ้นขี่ฟรี ไม่คืนวัตถุดิบ; เชื่อมคาถาผสานธาตุจักรวาลกับสูตร3ใบนี้ด้วย
- 016 คืนเพื่อนก่อนคืนศัตรู ห้ามโจมตีตรงหลังคืนเพื่อนสำเร็จจนจบเทิร์นตามสเปก
- ปรับAIให้เล่นคอมโบคืนมือ เก็บตัวสำหรับบอส และตัดสินใจจั่ว/กาลอย่างมีเหตุผล
- เพิ่มทดสอบตามเอกสาร ทั้งเป้าหาย สนามเต็ม กองหมด sourceหาย โควต้า การเปลี่ยนโซน และกฎเดิมไม่ถอยหลัง
- รัน npm test, npm run lint, npm run build และจำลอง preset TH07 พบทุกสำรับเดิม เป้าหมาย40–60%เป็นเป้าหมาย ไม่ใช่ผลที่ยืนยันแล้ว
- รายงานผลจริงก่อนปรับตัวเลข/เผ่า/ธาตุ/เนื้อหาเอฟเฟกต์ ถ้าสเปกขัดกันให้แยกข้อไม่แน่ใจ ไม่แก้ความหมายเงียบ ๆ
- เมื่อengineและAIรองรับจริงแล้วจึงแก้คำอธิบายpresetที่ระบุว่ารอengine
- ห้าม commit/push
