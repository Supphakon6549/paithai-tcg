# 🎴 GDD — ไพ่ไทย (Thai Card Game)
**Game Design Document v0.1**
_Last Updated: July 2026_

---

## 📌 Vision Statement

เกมการ์ดสะสมสไตล์ไทย ที่ดึง lore จากตำนาน เทพ อสูร และวิถีชีวิตไทยโบราณ
มี mechanic ลึกแบบ Yu-Gi-Oh! แต่ทุกอย่างเป็น original ทั้งหมด — artwork, ชื่อ, lore
**Philosophy:** "การ์ดดูธรรมดา → ทำพิธีถูก → กลายเป็นของที่คู่แข่งกลัว"

## 🃏 ประเภทการ์ด (Card Types)

### 1. การ์ดมอนสเตอร์ (Monster Card)
- มีค่า **ATK / DEF / Level / ธาตุ / เผ่า**
- วางได้ทั้ง face-up (Attack) และ face-down (Defense)
- Level 1–4: Normal Summon ได้เลย
- Level 5–6: ต้องสังเวย 1 ตัว
- Level 7+: ต้องสังเวย 2 ตัว

### 2. การ์ดเวทมนตร์ (Spell Card)
- ใช้ได้ทันทีในช่วง Main Phase
- ประเภทย่อย: ใช้ครั้งเดียว / ต่อเนื่อง / สนาม / Equip / Quick-Play

### 3. การ์ดกับดัก (Trap Card)
- ต้องวางคว่ำ 1 เทิร์นก่อนใช้
- เปิดใช้ได้ตอบโต้ฝ่ายตรงข้าม
- ประเภทย่อย: ใช้ครั้งเดียว / ต่อเนื่อง / Counter

### 4. การ์ดพิธีกรรม (Ritual Card)
- ใช้คู่กับมอนสเตอร์ระดับ Ritual เท่านั้น
- ต้องสังเวยมอนสเตอร์ตามเงื่อนไขที่ระบุในการ์ด

## ⚡ ธาตุ (Elements) — 8 ธาตุ

| สัญลักษณ์ | ธาตุ | ชื่อไทย | ตัวอย่างมอนสเตอร์ |
|----------|------|---------|-----------------|
| 🔥 | ไฟ | อัคนี | นาคราช, ทศกัณฑ์ |
| 💧 | น้ำ | วารี | พญานาค, เงือก |
| 🌿 | ดิน | ปฐวี | ช้างเอราวัณ, ยักษ์ดิน |
| 💨 | ลม | วายุ | ครุฑ, เทพอากาศ |
| ⚡ | ฟ้า | อาสนี | พระอินทร์, เทพสายฟ้า |
| 🌑 | มืด | ตมะ | ผีตาโขน, อสูร |
| ✨ | แสง | โชติ | เทวดา, กินนรี |
| 🌀 | ศูนย์ | ศูนยตา | พระพรหม, อนันตนาค |

### ระบบหักล้างธาตุ (Element Weakness)
```
อัคนี  > วายุ   (ไฟเผาลม)
วารี   > อัคนี  (น้ำดับไฟ)
ปฐวี   > อาสนี  (ดินดูดฟ้า)
อาสนี  > วารี   (ฟ้าช็อคน้ำ)
โชติ   > ตมะ   (แสงขับมืด)
ตมะ   > ศูนยตา (มืดกลืนศูนย์)
ศูนยตา > โชติ  (ศูนย์ลบล้างแสง)
วายุ   > ปฐวี  (ลมกัดดิน)
```
_เมื่อธาตุได้เปรียบ: ATK +300 ในการต่อสู้ครั้งนั้น_

## 🏹 ระบบเผ่า (Tribe System)

### เผ่าสัตว์ — วงจร Weakness
```
🦅 นก  →แพ้→  🐘 สัตว์ใหญ่
🐘 สัตว์ใหญ่  →แพ้→  🐍 สัตว์เลื้อยคลาน
🐍 สัตว์เลื้อยคลาน  →แพ้→  🌿 พืช
🌿 พืช  →แพ้→  🦟 แมลง
🦟 แมลง  →แพ้→  🦅 นก
```

### เผ่าวิญญาณ — วงจร Weakness
```
👹 อสูร  →แพ้→  💀 วิญญาณ
💀 วิญญาณ  →แพ้→  👼 เทวดา
👼 เทวดา  →แพ้→  👹 อสูร
```

### เผ่ามนุษย์ — 8 เผ่าย่อย (Neutral แต่มี Synergy)

| เผ่าย่อย | บทบาท | จุดเด่น |
|---------|-------|---------|
| ⚔️ ทหารหาญ | นักรบ, แม่ทัพ | ATK สูง, บัฟเมื่อสู้หมู่ |
| 🔮 โหราจารย์ | หมอดู, นักพยากรณ์ | ดูการ์ดในสำรับ, จัดการ deck |
| 🌿 หมอยา | หมอพื้นบ้าน, หมอผี | ฮีล LP, ถอดคำสาป, poison |
| 👑 ราชวงศ์ | กษัตริย์, เจ้าหญิง | บัฟการ์ดในสนามทั้งหมด |
| 🎭 โขน | นักแสดง, ช่าง | copy effect ของฝ่ายตรงข้าม |
| 🏹 พรานป่า | นักล่า, ลูกเสือ | ลด DEF ศัตรู, ซุ่มโจมตี |
| ⛵ พ่อค้าสำเภา | พ่อค้า, นักเดินทาง | ดึงการ์ดพิเศษ, trade mechanic |
| 🔨 ช่างหลวง | ช่างทอง, ช่างอาวุธ | สร้าง Relic Cards, buff อาวุธ |

### Tribe Synergy (มนุษย์)
```
มนุษย์ในสนาม 3 ตัว+       → bonus "ยุทธศาสตร์"
มนุษย์ต่างเผ่าย่อย 3 เผ่า+ → bonus "พันธมิตร"
ราชวงศ์ + ทหารหาญ          → combo "กองทัพหลวง" ATK +500 ทั้งสนาม
โหราจารย์ + หมอยา           → combo "คณาจารย์" ใช้เวทได้ฟรี 1 ใบ/เทิร์น
```

_เมื่อเผ่าได้เปรียบ: ATK +200 ในการต่อสู้ครั้งนั้น_

## 🌟 ระบบอัญเชิญ (Summoning System)

### 1. อัญเชิญธรรมดา (Normal Summon)
Level 1–4 วางได้เลย 1 ครั้ง/เทิร์น

### 2. อัญเชิญสังเวย (Tribute Summon)
- Level 5–6 → สังเวย 1 ตัว
- Level 7+ → สังเวย 2 ตัว
- ใช้สิทธิ์เดียวกับอัญเชิญธรรมดา: เทิร์นละ 1 ครั้งรวมกัน (อัญเชิญธรรมดา **หรือ** สังเวย)
- สังเวยได้เฉพาะมอนสเตอร์บนสนามเรา (รวมตัวที่เพิ่งลงเทิร์นนี้) ตัวที่ถูกสังเวยลงสุสาน
- ตัวใหม่ลงช่องของตัวที่ถูกสังเวย จึงอัญเชิญได้แม้สนามเต็ม 5 ช่อง

### 3. พิธีอัญเชิญ (Ritual Summon) ⭐
ต้องครบ 3 องค์ประกอบ:
- การ์ดมอนสเตอร์ Ritual ในมือ
- การ์ดพิธีกรรมที่ระบุชื่อพิธีตรงกัน
- เครื่องสังเวยครบ Level ตามที่กำหนด

**ตัวอย่าง:**
> "พิธีบวงสรวง" → อัญเชิญ "พระพิฆเนศมหาเทพ" (Level 8)
> ต้องสังเวยมอนสเตอร์รวม Level ≥ 8

### 4. อัญเชิญผสาน (Fusion Summon)
ผสาน 2 ตัว + คาถาผสาน "มนต์สังคหะ"
```
ครุฑ + นาคราช        → ครุฑนาคา (Level 9)
ทหารหาญ + ม้าศึก     → แม่ทัพขี่ม้า (Level 6)
โหราจารย์ + ตำราโบราณ → จอมเวทย์แห่งศาสตร์ (Level 7)
```

### 5. อัญเชิญจากดวงวิญญาณ (Spirit Summon) 🆕
- อัญเชิญจาก Graveyard โดยใช้ "น้ำมนต์" ที่สะสม
- น้ำมนต์สะสมได้จากการทำพิธีกรรมและการสังเวย

## 🌱 ระบบวิวัฒนาการ (Evolution System)

### เส้นทางที่ 1 — Ritual Path
```
[เด็กวัด] Lv.1
    ↓ ทำพิธีบวช (ใช้การ์ดพิธี "บรรพชา")
[สามเณร] Lv.3  (+เวทมนตร์)
    ↓ อุปสมบทครบ 2 เทิร์น
[พระอาจารย์] Lv.6  (+ฮีล +ถอดคำสาป)
    ↓ พิธีมหาสังฆทาน (สังเวย 3 เทิร์น)
[ครูบาศรีวิชัย] Lv.10  (ภูมิคุ้มกันเวทมนตร์, ฮีล LP ทุกเทิร์น)
```

### เส้นทางที่ 2 — XP Path
การ์ดบางใบมี "ช่องประสบการณ์" ต้องผ่านเงื่อนไขในเกม
```
[ลูกพราน]
    ↓ ทำลายมอนสเตอร์ 2 ตัว
[พรานหนุ่ม]  (ATK +400 เมื่อมีเผ่าสัตว์บนสนาม, ซุ่มโจมตีได้)
    ↓ ทำลายมอนสเตอร์อีก 3 ตัว
[เจ้าพรานแห่งไพร]  (ยิงได้ 2 ครั้ง/เทิร์น, ลด DEF ศัตรู 30%)
```

**คำอธิบายความสามารถ**
- **บัฟ ATK +400 (พรานหนุ่ม):** ได้เมื่อบนสนามเรามีมอนสเตอร์เผ่าสัตว์อย่างน้อย 1 ตัว (นักล่าคู่กับสัตว์ป่า) —
  ไม่ให้แบบไม่มีเงื่อนไข เพราะจะได้ ATK 2,000 ซึ่งแรงเกินมอนสเตอร์ระดับ 4 ตัวอื่น (สูงสุด 1,800)
- **ซุ่มโจมตี:** เมื่อมอนสเตอร์ที่มีความสามารถนี้เป็นฝ่ายโจมตี มอนสเตอร์ฝ่ายรับ **ไม่ได้รับโบนัสธาตุและเผ่า**
  ในการต่อสู้ครั้งนั้น (ฝ่ายโจมตียังได้โบนัสของตัวเองตามปกติ) — ไม่มีผลเมื่อเป็นฝ่ายถูกโจมตี

### กติกาเอฟเฟกต์การ์ดที่ใช้ในเกมแล้ว
- เอฟเฟกต์ทำงานเฉพาะการ์ดที่ **หงาย** อยู่บนสนาม (การ์ดคว่ำไม่มีผล และไม่นับเป็นเงื่อนไข)
- การ์ดคว่ำที่ถูกโจมตีจะเปิดหงายก่อนคำนวณ เอฟเฟกต์ของมันจึงมีผลในการต่อสู้นั้น
- บัฟ/ลด ATK จากเอฟเฟกต์ไม่บวกเข้า DEF และ ATK ต่ำสุดคือ 0
- คิดความเสียหายก่อนทำลายการ์ด (เอฟเฟกต์ลดความเสียหายของตัวที่แพ้ยังมีผลในการต่อสู้นั้น)
- **ตีทะลุ (อสูรทศกัณฐ์จำแลง):** ตีตัวตั้งรับที่ DEF ต่ำกว่า → ศัตรูเสียครึ่งหนึ่งของส่วนต่าง (ปัดลง)
  · แม่ทัพขี่ม้าศึกตีทะลุเต็มจำนวนของส่วนต่าง
- **โจมตี 2 ครั้ง (ทหารเสือดาบสองมือ):** เช็ก "ศัตรูมีมอนสเตอร์มากกว่าเรา" ทุกครั้งที่ประกาศโจมตี
- **ขุนศึกอาทมาฏ:** ทหารหาญ **ตัวอื่น** ฝ่ายเรา ATK +300 (ไม่รวมตัวเอง)
- **ช้างศึกไอยรา:** มีทหารหาญหงายบนสนาม → อัญเชิญได้โดยไม่ต้องสังเวย (ยังนับเป็นสิทธิ์อัญเชิญของเทิร์น)
  · ขณะหงายอยู่บนสนาม เจ้าของรับความเสียหายจากการต่อสู้ครึ่งเดียว (ปัดลง)
- **พญาครุฑเวนไตย:** หลังคำนวณความเสียหาย ทำลายคู่ต่อสู้เผ่าสัตว์เลื้อยคลาน แม้ครุฑจะแพ้ในการต่อสู้นั้น
- **ขุนศึกอาทมาฏ:** เมื่อประกาศโจมตี ฝ่ายตรงข้ามเปิดกับดักตอบโต้การโจมตีนั้นไม่ได้

### ความสามารถที่กดใช้ / เวท / พิธีกรรม / กับดัก (ใช้ในเกมแล้ว)
- **ความสามารถที่กดใช้:** มอนสเตอร์ต้องหงายอยู่บนสนาม ใช้ในเฟสหลักของเรา
  · "เทิร์นละ 1 ครั้ง" นับต่อใบ เว้นแต่การ์ดระบุ "ต่อชื่อการ์ด" (เช่น พระอินทร์ จอมอาสนี)
  · ตัวปรับ ATK "จนจบเทิร์น" หมดผลเมื่อเปลี่ยนเทิร์น
- **เวทสนาม:** ใช้ในเฟสหลัก วางในช่องเวทสนาม ใบเดิม (ถ้ามี) ลงสุสาน
- **พิธีกรรม:** ใช้ในเฟสหลัก ต้องมีมอนสเตอร์พิธีกรรมเป้าหมายในมือ
  · สังเวยมอนสเตอร์จากมือและ/หรือสนามเรา (หงายหรือคว่ำก็ได้) ระดับรวม ≥ ที่การ์ดกำหนด
    หรือใช้ "ตัวแทน" ที่การ์ดระบุเพียงใบเดียว (เอราวัณ → พิธีบวงสรวงจอมเทวา, พระอาจารย์ → พิธีบรรพชาฯ)
  · อัญเชิญท่าโจมตีหงายหน้า ไม่ใช้สิทธิ์อัญเชิญปกติ · การ์ดพิธีกรรมลงสุสาน
  · หลังสังเวยต้องมีช่องมอนสเตอร์ว่าง
- **กับดัก:** วางคว่ำในเฟสหลัก เปิดได้ตั้งแต่เทิร์นถัดไป (ไม่ใช่เทิร์นที่วาง)
  · เมื่อฝ่ายตรงข้ามประกาศโจมตีและเข้าเงื่อนไข เกมหยุดให้ฝ่ายรับเลือก "เปิด / ไม่เปิด" ก่อนคำนวณ
  · การโจมตีที่ถูกยกเลิกนับว่าใช้สิทธิ์โจมตีแล้ว

### เส้นทางที่ 3 — Fusion Path
```
[ทหารหาญ] + [ม้าศึก]           → [แม่ทัพขี่ม้า]
[นักรบ] + [ครุฑศักดิ์สิทธิ์]    → [อัศวินครุฑาวตาร] ✨ Legendary
```

## 💎 ระบบความหายาก (Rarity System)

| ระดับ | ชื่อ | ลักษณะ | Drop Rate |
|-------|------|--------|-----------|
| ⬜ | สามัญ | กระดาษขาว ขอบดำ | ~55% |
| 🟫 | ทองแดง | ขอบทองแดง shimmer | ~25% |
| ⬜ | เงิน | ขอบเงิน + ลายไทยนูน | ~12% |
| 🟨 | ทอง | ขอบทอง + holographic | ~6% |
| 💠 | มรกต | กรอบมรกต + full foil | ~1.5% |
| 🌟 | เทพ (Divine) | ทองคำเปลว + นาค, 1 ใบ/เซ็ต | ~0.5% |

### โครงสร้างแพ็ค (9 ใบ/แพ็ค)
```
สามัญ    5 ใบ  (guaranteed)
ทองแดง  2 ใบ  (guaranteed)
เงิน     1 ใบ  (guaranteed)
Rare Slot 1 ใบ (ทอง/มรกต/เทพ ตาม drop rate)
```

### ระบบตราสัญลักษณ์ (Seal System)
- ทุกการ์ดมีตราที่ยังไม่เปิดอยู่ด้านหลัง
- เมื่อใช้ครบเงื่อนไข → ตราเปิด → ปลดล็อก alternate art หรือ bonus effect
- ทำให้การ์ด "สามัญ" มีคุณค่าได้

## 🗺️ เซ็ตการ์ด (Card Sets)

### เซ็ต 1 — นาคาแห่งบาดาล
**ธีม:** พญานาค, เงือก, สัตว์น้ำศักดิ์สิทธิ์
**ธาตุหลัก:** วารี + ตมะ
**Key Cards ที่ต้องสะสมให้ครบ:**
```
□ พญานาคราช       (มรกต)
□ นางนาคมเหสี     (ทอง)
□ บริวารนาค x3    (เงิน)
□ วังบาดาล        (ทอง - Field Spell)
□ พิธีอัญเชิญนาค  (เงิน - Ritual)
□ นาคเทพบุตร      (เทพ - Divine)
```
_เมื่อครบ → ปลดล็อก "ตำนานบาดาล" lore สุดท้ายของเซ็ต_

### เซ็ต 2 — เทพตรีมูรติ
**ธีม:** พระพรหม, วิษณุ, ศิวะ และบริวาร
**ธาตุหลัก:** โชติ + ศูนยตา

## ⚙️ กฎเกมหลัก (Core Rules)

### ค่าเริ่มต้น
```
LP เริ่มต้น    : 8,000
การ์ดในมือเริ่มต้น : 5 ใบ
Draw ต่อเทิร์น : 1 ใบ
Monster Zone   : 5 ช่อง
Spell/Trap Zone : 5 ช่อง
Field Zone     : 1 ช่อง (เวทสนาม — ลงใบใหม่ ใบเก่าลงสุสาน)
สำรับหลัก      : 40 ใบ
กองพิเศษ       : มอนสเตอร์ผสานร่าง แยกจากกองหลัก ไม่ต้องจั่ว
```

### ผังกระดาน (ฝั่งเรา — ฝั่งคู่ต่อสู้หมุน 180°)
```
[เวทสนาม]   [มอนสเตอร์ ×5]      [สุสาน]
[กองพิเศษ]  [เวท/กับดัก ×5]     [กองการ์ด]
```

### กติกาการต่อสู้ (กำหนดเพิ่ม)
- ต่อสู้แบบ ATK ปะทะ ATK: ATK สูงกว่าทำลายอีกฝ่าย และเจ้าของตัวที่แพ้เสีย LP เท่าส่วนต่าง
- ATK เท่ากัน: ทำลายทั้งคู่ ไม่มีใครเสีย LP
- ฝ่ายตรงข้ามไม่มีมอนสเตอร์: โจมตีตรงได้ เสีย LP เท่า ATK ของตัวที่โจมตี
- มอนสเตอร์แต่ละตัวโจมตีได้เทิร์นละ 1 ครั้ง
- โบนัสธาตุ (+300) และเผ่า (+200) ได้ทั้งฝ่ายโจมตีและฝ่ายรับ ซ้อนกันได้
- ผู้เล่นที่เริ่มก่อน: เทิร์นแรกไม่จั่ว และโจมตีไม่ได้
- อัญเชิญปกติได้ในเฟสหลัก 1 หรือ 2 เทิร์นละ 1 ครั้ง
- **ท่าตั้งรับ = วางคว่ำ:** อัญเชิญปกติ/สังเวยแบบวางคว่ำได้ อีกฝ่ายไม่รู้ว่าเป็นการ์ดอะไรจนถูกโจมตี (การ์ดคว่ำไม่นับเป็นเงื่อนไขเอฟเฟกต์)
- มอนสเตอร์ท่าตั้งรับโจมตีไม่ได้ และมีตัวตั้งรับอยู่ก็โจมตีตรงไม่ได้
- **ATK ปะทะ DEF:** ATK > DEF → ตัวตั้งรับถูกทำลาย เจ้าของไม่เสีย LP · ATK < DEF → ฝ่ายโจมตีเสีย LP เท่าส่วนต่าง ไม่มีใครถูกทำลาย · เท่ากัน → ไม่มีอะไรเกิดขึ้น
- โบนัสธาตุ/เผ่าบวกเข้า DEF ได้ (ซุ่มโจมตียกเลิกได้) แต่บัฟ ATK จากเอฟเฟกต์ไม่บวกเข้า DEF
- **เปลี่ยนท่า:** ในเฟสหลัก ตัวละ 1 ครั้ง/เทิร์น ยกเว้นเทิร์นที่เพิ่งลงสนามหรือโจมตีไปแล้ว — คว่ำ → หงายท่าโจมตี, โจมตี ↔ ตั้งรับแบบหงาย

### ลำดับ Phase
```
1. Draw Phase    → จั่วการ์ด 1 ใบ
2. Standby Phase → ตรวจ effect ต่อเนื่อง
3. Main Phase 1  → วางการ์ด, ใช้เวท, อัญเชิญ
4. Battle Phase  → ประกาศโจมตี
5. Main Phase 2  → ใช้การ์ดเพิ่มเติม
6. End Phase     → ส่งการ์ดเกิน 6 ใบ ทิ้ง
```

### เงื่อนไขชนะ
- ลด LP ฝ่ายตรงข้ามเหลือ 0
- ฝ่ายตรงข้ามจั่วการ์ดไม่ได้ (Deck Out) — แพ้เมื่อถึงตาจั่วแต่กองการ์ดหมด
- เงื่อนไขพิเศษของการ์ดบางใบ
