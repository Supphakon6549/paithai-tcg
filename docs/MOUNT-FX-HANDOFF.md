# ส่งต่อ Gemini: ทำฉาก "ขึ้นขี่" ให้เป็นช่วงว้าว

7 พฤศจิกายน 2026 · เขียนโดย Claude (ฝั่ง engine)

## ทำไมต้องทำ

ผู้ใช้ตกลงแล้วว่าจุดขายหลักของเกมคือ **"คู่หูในตำนาน"**: คนจับคู่กับสัตว์ ผี นาค หรือเทพ แล้วรวมเป็นร่างใหม่ด้วยการขึ้นขี่
ด่านแนะนำจะให้ผู้เล่นได้ขึ้นขี่เสือเร็วที่สุด ดังนั้นฉากขึ้นขี่คือ **ช่วงว้าวแรกที่ผู้เล่นใหม่ทุกคนจะเห็น**
ตอนนี้มีฉากอยู่แล้ว (`ShowcaseStage` kind `mount`, 1.65 วินาที) แต่ยังเป็นการ์ดขนาดเท่ากับฉากผสานร่างทั่วไป ยังไม่รู้สึกพิเศษ

## สัญญาณจากเกม (มีอยู่แล้ว ไม่ต้องแก้ engine)

หลัง action `mount` เกมจะแนบ `event` ไว้ใน log entry แบบเดียวกับที่ `BattleFx.jsx` ใช้อยู่ตอนนี้

```js
event.showcase = {
  player,            // 'player' | 'ai'
  kind: 'mount',
  label: '🐎 ขึ้นขี่',
  cardId,            // ร่างขี่ (การ์ดจากกองพิเศษ)
  resultCardId,      // ร่างขี่ที่ลงสนาม (id เดียวกับ cardId)
  materialCardIds,   // [คน, สัตว์] เรียงให้แล้วเสมอ
}
event.placed = [{ player, uid, cardId, zone }]  // ช่องที่ร่างขี่ลง → ใช้ findCardOrZoneRect หาตำแหน่ง
event.destroyed = [...]                          // คนกับสัตว์ที่ออกจากสนาม (ช่องเดิมของทั้งสอง)
```

- **คำกริยา:** `getMountVerb(card)` จาก `src/engine/effects.js` คืนค่า `'ขึ้นขี่'` หรือ `'รวมร่าง'`
  - `'ขึ้นขี่'`: ร่างคนขี่สัตว์ th03-013 ถึง th03-016 → ใช้ฉากคนกระโดดขึ้นหลัง
  - `'รวมร่าง'`: th03-017 (ต้นไทร) และ th03-019 (ราชินีต่อ) → ไม่มีคนกับสัตว์ ควรใช้ฉากรวมร่างแบบอื่น
  - ตอนนี้ label ถูกตั้งเป็น '🐎 ขึ้นขี่' ทั้งสองแบบ ถ้าต้องการให้ผมส่ง verb มาใน `showcase` ด้วย บอกผมได้ แก้แค่บรรทัดเดียว
- **ลงจากหลัง:** kind `dismount` (ร่างขี่ถูกทำลาย แล้วคืนวัตถุดิบ 1 ตัว) ใช้ฉากเดิมได้ ไม่ต้องทำใหม่
- **ร่างขี่ที่เป็นบอส:** ถ้า `isBossCard(resultCardId)` เป็นจริง ระบบจะเปลี่ยนไปใช้ `BossSummonStage` เองอยู่แล้ว
- **ทดสอบ:** ทำ `window.__previewMount(...)` แบบเดียวกับ `__previewBossSummon` จะช่วยให้ดูฉากได้โดยไม่ต้องเล่นจนถึงจังหวะนั้น

## เวลาและข้อจำกัด

| กรณี | ยาวสุด |
|---|---|
| ขึ้นขี่ร่างนั้นครั้งแรกในเกม (ฉากเต็ม) | **2.5 วินาที** |
| ร่างเดิมครั้งต่อไปในเกมเดียวกัน (ฉากสั้น) | **1.2 วินาที** |
| ฝั่ง AI ขึ้นขี่ | ใช้ฉากสั้นเสมอ |
| ลดการเคลื่อนไหว (reduced motion) | 1.1 วินาที เหลือแค่ชื่อร่างกับแสงวาบ (ตามค่า `SHOWCASE_REDUCED_MS` เดิม) |

- **ข้ามได้:** แตะจอหรือกด Space/Enter/Escape แล้วข้ามได้ เหมือนฉากบอส
- **ตัวเกมไม่รอฉาก:** สถานะเกมเปลี่ยนทันที ฉากเป็นแค่ภาพ ดังนั้นเวลาที่ตั้งต้องตรงกับเวลาที่ฉากหายจริง
  - ร่างขี่บนสนามต้องถูกซ่อน (`resultUid`) จนการ์ดบินลงช่อง
- **มือถือแนวตั้ง 320–412px:** ฉากต้องไม่ล้นจอ ห้ามเพิ่ม horizontal scroll
  - ผมเพิ่งแก้ปัญหาการ์ดล้นจอบนมือถือไป
- **อย่าบังปุ่มนานเกินฉาก:** ชั้น fx ต้องคง `pointer-events: none`

## สิ่งที่อยากให้รู้สึก (ข้อเสนอ ปรับได้)

1. **สองตัวเข้าหากัน:** คนกับสัตว์ลอยออกจากช่องเดิมของตัวเองบนกระดาน ไม่ใช่โผล่กลางจอเฉย ๆ
   - ใช้ตำแหน่งช่องจาก `event.destroyed`
2. **จังหวะกระโดด:** คนกระโดดขึ้นหลัง แล้วหยุดภาพครึ่งจังหวะ (hit-stop) พร้อมแสงวาบ
3. **เผยร่างใหม่:** การ์ดร่างขี่ใหญ่กว่าฉากผสานร่างปกติ พร้อมชื่อร่าง และ ATK ที่เพิ่มขึ้นเทียบกับคนตัวเดิม
   - เช่น ATK 1,200 → 2,400
   - ให้ผู้เล่นใหม่เห็นทันทีว่า "ขึ้นขี่แล้วเก่งขึ้น"
4. **ลงสนาม:** ร่างขี่วิ่งลงช่องจริง มีฝุ่นหรือแรงกระแทกเล็ก ๆ บนกระดาน
   - ไม่ต้องใหญ่เท่าสายฟ้าหรือน้ำท่วมของบอส

**ตัวเลข ATK:** หาได้จาก `getCardById(id).atk` ทั้งของคน (`materialCardIds[0]`) และของร่างขี่
