# หน้าการ์ดนาคา รุ่น 2 — ยึดองค์ประกอบภาพที่อนุมัติ
27 ตุลาคม 2026 · ผู้รับผิดชอบ: Codex
ปัญหารุ่นแรก: foreground ที่แยกใหม่มีสัดส่วนแนวตั้งยาวกว่าองค์ประกอบเดิม แต่แผงข้อมูลเริ่มสูงเกินไป จึงบังขนด กรอบ CSS ลดรายละเอียดและการตัดสายน้ำออกทำให้ความลึกหายไป
แก้โดยใช้ภาพแม่แบบเต็มใบที่ไม่มีตัวหนังสือ รักษาตัวละคร สายน้ำ กรอบทอง ฉาก และเงาซ้อนกันในภาพเดียว แล้ววางชื่อ/ธาตุ/เผ่า/ค่าพลัง/เอฟเฟกต์/flavor/code จากข้อมูลสดลงในช่องโปร่งใสตามตำแหน่งแม่แบบ
ไม่ใช่ parallax หลายเลเยอร์ในรุ่นนี้ แต่เป็นมิติที่วาดในภาพซึ่งคงองค์ประกอบตรงภาพที่ผู้ใช้เลือก; เลเยอร์โปร่งใสรุ่นแรกยังเก็บเป็นต้นฉบับแต่ไม่ได้ใช้บนการ์ดนี้
