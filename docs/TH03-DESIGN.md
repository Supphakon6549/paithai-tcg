## กติกากลางสำหรับนำเอฟเฟกต์ไปใช้
- สัตว์ = มอนสเตอร์ที่ tribe หรือ secondaryTribe อยู่ใน bird/insect/plant/reptile/largeBeast รวมพืชตามระบบเกม ไม่ใช่การจำแนกชีววิทยา
- animalSet คือเซตของเผ่าสัตว์จากสองช่อง เผ่ามนุษย์ไม่เพิ่มจำนวนเผ่าสัตว์ คน+สัตว์ได้จุดแข็งและจุดอ่อนทั้งสอง ไม่ยกเว้นแพ้ทาง
- “สัตว์ต่างเผ่า” ของ007/010: ต้องมีสองตัวจริง และ animalSet ไม่ทับกัน หนึ่งตัวสองเผ่าไม่เปิดสนามเอง
- จ่าฝูง006เป็นข้อยกเว้นวิธีนับ: รวมเซตเผ่าสัตว์ของตัวอื่นที่หงาย แล้วลบ largeBeast ของบอส นับชนิดที่เหลือ สูงสุด3 ไม่ได้นับจำนวนตัว เผ่ามนุษย์ไม่นับ
- วงจร src/data/tribes.js: bird > insect > plant > reptile > largeBeast > bird; โบนัสเผ่า200 และธาตุ300 อย่างละหนึ่งครั้ง ไม่คูณเพราะสองเผ่า
- เอฟเฟกต์สนาม/ออร่าและการกดใช้ต้องหงายและไม่ถูกปิดเอฟเฟกต์ เว้น trigger ออกจากสนามที่ระบุเฉพาะ ใช้เจ้าของ/ผู้ควบคุมตามแต่ละหัวข้อ
- “ใบละครั้งต่อเทิร์น” บันทึก physical instance + turn ID ไม่รีเซ็ตด้วยการออก/กลับ/คว่ำ; “ชื่อนี้เทิร์นละครั้ง” บันทึก player + card ID + turn ID รวมทุกสำเนา
- กดใช้ที่มีต้นทุนตรวจเป้า/ต้นทุนครบก่อน จ่ายและบันทึกสิทธิ์เมื่อประกาศ ผลถูกยกเลิกภายหลังไม่คืนต้นทุน/สิทธิ์; passive ไม่ใช้สิทธิ์
- ช่วงจบเทิร์นถัดไปของศัตรู: จับฝ่ายศัตรูและ end-turn ID ถัดไปตอนแก้ผล ไม่เลื่อนอายุด้วยการเปลี่ยนผู้ควบคุม หมดหลังจบหน้าต่างเอฟเฟกต์จบเทิร์นนั้น
- บัฟ/ลดค่าที่สร้างแล้วคงอายุเมื่อแหล่งกำเนิดหาย เป้าคว่ำหรือเปลี่ยนฝ่ายไม่รีเซ็ตอายุ เป้าออกสนามล้างค่าและไม่ติดไป instance ที่กลับมา คำนวณ ATK อย่างน้อย0
- ไม่เปลี่ยนเอฟเฟกต์การ์ดชุดอื่น บัฟจากแหล่งคนละชื่อซ้อนได้ เว้นมีคำห้าม; ตารางสมดุลไม่นับบัฟไม่จำกัดจากชุดอื่น

### ระบบเติบโต
ทะเบียนปัจจุบัน: 001 cap3 (+200 ATK/DEF), 002 cap2 (+200 DEF), 017 cap3 (+100 ATK/DEF) พืชอื่นไม่มีแต้มเอง เพียงมี tribe plant ไม่ทำให้รับแต้มได้
เมื่อเข้าหงายเริ่ม0 จบเทิร์นผู้ควบคุมถ้ายังหงายได้1 ครั้งเดียวต่อ physical/turn รวมเทิร์นที่อัญเชิญ; capบังคับทุกแหล่ง
คว่ำหรือออกสนามล้างแต้ม เปลี่ยนฝ่ายคงแต้ม; ปิดเอฟเฟกต์คงแต้มแต่โบนัสและการเติบโตประจำตัวไม่ทำงาน เวท011/ร่าง015ยังวางแต้มได้ถ้าหงาย มีทะเบียน และไม่เต็ม
ถอนแต้มเป็นต้นทุนของ008หรือ017ลดโบนัสทันที ไม่เกิด “ถูกทำลาย” จากการถอนแต้ม ไม่ใช่เพิ่มค่าฐาน;001ไม่มีการถอนแต้มแทนตายแล้ว

### 001 ต้นไทรเดินดิน
- ATK600/DEF1000 คงเดิม; เติบโตจบเทิร์นเรา +1 cap3, ATK/DEF+200 ต่อแต้ม

### วิธีขึ้นขี่ (shared action)
- ผู้เล่นในmainของตน ไม่มีbattle/เอฟเฟกต์ค้าง เลือกร่าง013–016ในกองพิเศษและมอนสเตอร์หงายฝ่ายตนสองใบที่ตรงช่องสูตรคน/สัตว์
- ใบเดียวสองเผ่าไม่พอสองช่อง แต่สองสำเนาที่ต่างuidใช้ได้ถ้าจับคู่สูตรได้; ท่าATKหรือDEFใช้ได้ เคยโจมตีแล้วก็ใช้ได้ เพราะผู้ใช้ไม่ได้กำหนดห้าม
- ตรวจส่งสุสานและข้อห้ามวัสดุทั้งคู่ก่อนเปลี่ยนstate ส่งสองตัวลงสุสานเจ้าของพร้อมกันเป็นต้นทุน แล้วspecialร่างหงายATKลงช่องว่างจากกองพิเศษ
- ขึ้นขี่รวมทุกชื่อ013–016 **ผู้เล่นละ1ครั้งต่อเทิร์น** บันทึกเมื่อจ่ายต้นทุน ไม่ใช้normal summon ไม่ใช้เวท ไม่ส่งตัวที่สองหากคู่ไม่ครบ
- สนามเต็มใช้ช่องที่สองวัสดุออก ข้อห้ามspecial/ส่งสุสาน/ใช้เป็นวัสดุทำให้เริ่มไม่ได้ กรณีมีreplacementทำให้ไม่ลงสุสานไม่เปิดactionนี้
- หากเกิดการยกเลิกหลังจ่าย ต้นทุนและสิทธิ์ไม่คืน ร่างอยู่กองพิเศษถ้ายังไม่อัญเชิญสำเร็จ; ไม่triggerลงจากหลังจากการอัญเชิญไม่สำเร็จ
- วัตถุดิบส่งไม่ใช่ถูกทำลาย ไม่trigger001/004/ลงจากหลัง แต่triggerส่งสุสานอื่นให้engineจัดตามปกติหลังจบaction
- ร่างเป็นinstanceใหม่ในการลงสนาม ไม่รับbuff, growth, XP, สิทธิ์โจมตีใช้แล้วของวัสดุ; ห้ามโจมตีเฉพาะวัสดุไม่สืบทอด แต่ข้อห้ามใช้วัสดุห้ามส่งตั้งแต่ต้น
- ใช้ th01-013 คาถาผสานธาตุจักรวาลได้ด้วยสูตรเดียวกัน ใช้มือ/สนามรวมคว่ำตามfusionเดิม ตรวจข้อมูลจริงแบบส่วนตัว ไม่ใช้โควต้าขึ้นขี่และไม่ใช้normal; ร่างลงATKเหมือนกัน

### ลงจากหลัง (shared destruction trigger)
- บันทึก actual material physical IDs, เจ้าของ, graveyard-entry IDs และร่างที่รับวัสดุเมื่อผสาน/ขึ้นขี่สำเร็จทั้งสองวิธี ใช้สองใบจริงล่าสุด ไม่คืนการ์ดชื่อเดียวกันใบอื่น
- เมื่อร่างถูกทำลายจากสนามด้วยbattleหรือeffectและลงสุสาน ใช้ได้แม้คว่ำก่อนeffectทำลายถ้ายังมีประวัติอัญเชิญถูกต้อง; ดูผู้ควบคุมก่อนตายเป็นผู้ใช้ trigger
- เลือกได้หนึ่งวัสดุที่ยังอยู่สุสานของผู้ใช้trigger **ต่อเนื่องจากการส่งเป็นวัสดุครั้งนั้น** เรียกหงายDEFในช่องว่างของฝ่ายผู้ใช้ ไม่เอาใบของศัตรูคืนให้ตน
- ใบละ1ครั้งต่อเกมต่อ physicalร่าง ไม่ใช่ต่อชื่อหรือการอัญเชิญ; เครื่องหมายใช้แล้วอยู่แม้คืนกองพิเศษ/เปลี่ยนฝ่าย/อัญเชิญใหม่ สองร่างคนละphysicalมีสิทธิ์คนละครั้ง
- เลือกเปิดเมื่อมีเป้าถูกกฎหมายและช่อง ถ้าไม่มีเป้าหรือเต็มขณะเกิดtriggerให้ข้าม ไม่คิวรอถึงจบเทิร์น และไม่เสียโควต้าที่ยังไม่ได้เปิด
- เปิดแล้วบันทึกสิทธิ์ทันที เป้าหาย/ออกแล้วกลับสุสาน/ช่องเต็มก่อนแก้ให้ล้มเหลว ไม่มีเลือกใบใหม่และสิทธิ์ไม่คืน; ไม่รับวัสดุที่ออกจากสุสานไปแล้วกลับมาก่อนtriggerด้วย
- การคืนมือ/เนรเทศ/สังเวย/ส่งสุสานไม่ใช่ทำลายจึงไม่trigger; ถูกdestroyแต่แทนปลายทางเป็นนำออกเกมไม่triggerตามนิยามนี้
- วัสดุมีข้อจำกัดเช่นอัญเชิญด้วย012เท่านั้นต้องเคารพ; fusion/ritualวัสดุคืนได้เฉพาะเคยอัญเชิญถูกต้องและไม่มีข้อห้ามคืนพิเศษ เก็บproper-summoned flag ห้ามใช้การลงจากหลังข้ามข้อจำกัด
- ตัวที่คืนไม่ถือขึ้นขี่ใหม่ เริ่มแต้ม/บัฟ0 ใช้on-summonได้ตามชื่อและเทิร์นเดิม; ร่างที่กลับมาตอนหลังไม่มีประวัติคู่วัสดุใหม่จากการคืนชีพทั่วไป
- ถ้าใช้ร่างขี่เป็นวัสดุร่างใหม่ การส่งไม่trigger และทุกใบมีโควต้าลงจากหลังต่อเกม จึงไม่เกิดวงวนคืนตัวฟรีไม่สิ้นสุด

## ความแตกต่างจากชุดอื่น
พืชตั้งสนามเป็นคู่และรักษาแต้มเพื่อใช้ร่วมกับหมอช้าง/ต้นใหญ่ แมลงเรียกชื่อเดียวกันเพื่อสร้างรังและให้ด้วงป้องกันแต่ละตัว
ไม่อาศัยสุสานนับพลังหรือคำสาปแบบTH06; ราชินีใช้สุสานเป็นแหล่งคืนต่อหนึ่งใบในendเรา ไม่มีคำสาปตอนตาย
ไม่มีตีทะลุเต็มแบบแม่ทัพหรืออมตะทุกbattleแบบจอมทัพ; เกราะผูกเพื่อนและหนึ่งครั้งต่อผู้รับ ตัดเพื่อนหรือโจมตีซ้ำยังแก้ทางได้
ต้นใหญ่คืนวัสดุจริงหนึ่งใบเมื่อถูกทำลายตามร่างขี่ ไม่คืนตัวเองแบบแม่นาค และไม่ทำงานจากการส่งตัวเองรวมร่าง

## เรื่องราวและการตีความเพื่อเกม

- “ไพรมหาวัน” เป็นป่าสมมติที่ผสมลักษณะป่าไทย ไม่ใช่สถานที่อนุรักษ์จริงที่อ้างตำแหน่ง ภูมิทัศน์และตัวละครไม่มีการสวมชื่อบุคคลจริง
- นกเงือกและไทรใช้แรงบันดาลใจจากบทบาทการกระจายเมล็ดและความสัมพันธ์กับผลไม้ป่า เกมใช้การเลือกการ์ดสัตว์แทนการเพิ่มความหลากหลาย ไม่ใช่กลไกทางชีววิทยาตรงตัว ([กรมอุทยานฯ: นกชนหินและไทร](https://news.dnp.go.th/news/38496))
- เสือโคร่งอ้างอิงสัตว์จริงในป่าไทยและบทบาทผู้ล่าระดับสูง ส่วนการนำสัตว์หลายชนิดรวมพลังหรือร่วมฝูงเป็นแฟนตาซี ไม่ใช่ข้ออ้างว่าเสือโคร่งล่าเป็นฝูงกับนกและแมลง ([กรมอุทยานฯ: เสือโคร่งกับระบบนิเวศ](https://news.dnp.go.th/news/37679))
- หวายเป็นส่วนหนึ่งของพืชพื้นล่างในป่าไทย ตัวอย่างข้อมูลอุทยานถ้ำสะเกิน; รูปร่างเดินได้ ใบหน้า และการเรียกต้นไทรและสะสมแต้มแต่งขึ้น ไม่ใช่สิ่งมีชีวิตชนิดใหม่ที่ค้นพบ ([กรมอุทยานฯ: พืชป่าถ้ำสะเกิน](https://booking.dnp.go.th/parksdetail.php?id=97))
- ด้วงกว่างใช้ลักษณะด้วงมีเขาที่มีอยู่ในไทยเป็นแรงบันดาลใจ โดยชนิดในสกุลEupatorusมีเขาหลายรูปแบบ ภาพการ์ดเป็นด้วงกว่างแฟนตาซีขนาดใหญ่ ไม่ระบุเป็นภาพจำแนกชนิดทางอนุกรมวิธาน ([ศูนย์องค์ความรู้ทรัพยากรธรรมชาติ: ด้วงกว่าง](https://hub.mnre.go.th/th/knowledge/detail/65500))
- ต่อหัวเสือมีอยู่จริงในไทย; เกมใช้ภาพฝูงและรังเป็นเอกลักษณ์ การช่วยด้วง/แสงพลัง/ขนาดในภาพเป็นการแต่ง ไม่ใช่คู่มือเข้าหารังหรือเลี้ยงสัตว์ ([รายงานวิจัยต่อหัวเสือในประเทศไทย](https://elibrary.tsri.or.th/fullP/MRG5380080/MRG5080080_s01.pdf))
- เสือสมิงเป็นคติความเชื่อที่มีหลายสำนวน ตัวอย่างงานบันทึกนิทานชุมชนห้วยหินดำมีการสวมรอยมนุษย์ เกมเลือกภาพมนุษย์ค่อยเผยลายเสือ ไม่อ้างว่าคติทุกชุมชนเหมือนกันหรือมีจริง ([ฐานข้อมูลศูนย์มานุษยวิทยาสิรินธร](https://culturio.sac.or.th/storage/content/resource/Z7LLgGzuW27jB7w76vpWvXOtcep0XQkh.pdf))
