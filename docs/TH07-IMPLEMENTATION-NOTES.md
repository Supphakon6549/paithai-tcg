# TH07 — ข้อแตกต่างที่ผู้พัฒนา engine รายงาน

รับข้อมูลผ่านผู้ใช้วันที่ 30 ตุลาคม 2026 บันทึกเพื่อส่งต่อ ไม่ใช่ผลตรวจหรือทดสอบ engine โดยแชตงานภาพ และไม่ได้แก้สเปกหรือข้อมูลการ์ดตามรายการนี้

| การ์ด | พฤติกรรมที่รายงาน | ข้อแตกต่างจากเอกสาร |
|---|---|---|
| TH07-014 ผนึกสังข์ระงับมนต์ | เปิดในเฟสหลักของเรา หรือเมื่อศัตรูประกาศโจมตี | ยังเปิดในเฟสหลักของศัตรูไม่ได้ เพราะยังไม่มีจังหวะแทรก |
| TH07-002 นาคาผู้พิทักษ์มณีธาร | ค้นการ์ดอัตโนมัติเมื่อเข้าเงื่อนไข | ไม่มีขั้นถามว่าจะใช้เอฟเฟกต์หรือไม่ |
| TH07-007 ประตูวังวนบาดาล | จั่วอัตโนมัติเมื่อเข้าเงื่อนไข | ไม่มีขั้นถามว่าจะใช้เอฟเฟกต์หรือไม่ |
| TH07-010 นาคาอารักขาบัวแก้ว | ใช้การป้องกันอัตโนมัติเฉพาะเมื่อกำลังจะถูกทำลายหรือฝ่ายเราจะเสีย LP | ไม่ใช้สิทธิ์ในจังหวะที่ชนะการต่อสู้อยู่แล้ว |
| TH07-016 พญานาคราชมณีบาดาล | เลือกศัตรูที่จะคืนมือหลังคืนเพื่อนสำเร็จ | เอกสารให้เลือกเป้าหมายทั้งสองก่อนเปิดใช้ |

ผู้พัฒนา engine รายงานว่าแก้ไฟล์ของฝ่ายออกแบบเพียงคำอธิบายเด็คนาคาใน `src/data/preset-decks.json` โดยเอาคำว่า “รอ engine” ออกตาม handoff ฝ่ายงานภาพตรวจพบแล้วว่าคำอธิบายเด็คนาคาปัจจุบันไม่มีคำดังกล่าว ทั้งนี้ไม่ได้ตรวจ diff เพื่อยืนยันขอบเขตการแก้ทั้งหมด

ใช้คู่กับ `docs/TH07-DESIGN.md` และ `docs/TH07-CLAUDE-HANDOFF.md` หากจะปรับข้อความการ์ดหรือกติกาให้ตรง implementation ให้ประสานผู้ดูแล engine และผู้ใช้ก่อน งานภาพยังคงใช้ข้อความ HTML จากข้อมูลเกม และไม่แก้ `src/engine` หรือ `src/components/battle`
